# 🧠 AI Log Intelligence Engine

AI-powered log anomaly detection with real-time alerts 
and plain English explanations.

## Tech Stack
- Backend: Spring Boot 4.0.3 + PostgreSQL + WebSocket
- Frontend: React 18 + Vite + Tailwind CSS
- AI: Ollama + TinyLlama (local, free, no API cost)
- Infrastructure: Docker

## Features
- Real-time log analysis
- 40+ anomaly detection patterns
- AI explanations for each anomaly
- Live WebSocket dashboard
- PDF export reports

## Setup
1. docker compose up -d
2. Run Spring Boot in IntelliJ
3. cd frontend && npm run dev
4. Open http://localhost:5173
